# CSC2626 Imitation Learning for Robotics — Study Notes

Running, beginner-level study notes for CSC2626 (Imitation Learning for Robotics), written up week by week as the course goes.

**📖 Read the notes:** [The Imitation Loop](https://claude.ai/artifact/5Eh9TePpNpmwVvLmAbWPoG) — a running, browsable course notebook (nav per week + a cumulative glossary), publicly viewable with no sign-in required. The markdown in this repo is the same content in plain-text form.

## Contents

| File | What it is |
|---|---|
| [`week1-study-notes.md`](./week1-study-notes.md) | Week 1 — imitation learning vs. supervised learning: covariate shift, DAgger, teleoperation hardware, and multi-modal generative policies, with deep breakdowns of all 22 required and optional/appendix papers. |
| [`week2-study-notes.md`](./week2-study-notes.md) | Week 2 — optimal control and model-based RL: the Bellman-equation bridge, LQR/Riccati recursion, iLQR, MPC, MPPI, CEM, and learned world models, with deep breakdowns of all 19 required and optional/appendix readings. |
| [`week3-study-notes.md`](./week3-study-notes.md) | Week 3 — offline/batch reinforcement learning: RL terminology, QT-Opt, distribution shift, and the policy-constraint (BCQ, BEAR, TD3+BC) and value-conservatism (CQL, REM) solution families, with deep breakdowns of all 20 required, optional/appendix, and secondary-topic readings. |
| [`glossary.md`](./glossary.md) | A single, cumulative glossary of course terminology, grouped by the week each term is (or will be) covered. |
| [`CLAUDE.md`](./CLAUDE.md) | The project's own working notes for how these are generated and kept up to date. |

More `weekN-study-notes.md` files are added as the course progresses.
